01 / Focus

Research

My research explores safe machine learning applications in robotics and control, with a focus on safety-critical control methodologies using Control Barrier Functions.

I work on both the theoretical development of these methods and the practical challenges of deploying them on real-world robotic systems.

  • Control Barrier Functions
  • Safe machine learning
  • Model-based reinforcement learning
  • Model Predictive Control
  • Multi-robot interaction
  • LLM-based planning
  • Semantic scene graphs

02 / In practice

Selected
projects

01 Safe learning & predictive control

Safe model-based reinforcement learning

Developed a safe reinforcement learning framework for unknown, stochastic dynamics by jointly learning system dynamics and Control Barrier Functions with neural networks. Integrated uncertainty-aware CBF constraints into sampling-based Model Predictive Control for safe trajectory planning.

Validated the approach in robotic navigation simulations, demonstrating improved safety and competitive performance compared with existing safe reinforcement learning methods.

Read the safe reinforcement learning preprint  ↗
02 Safety & control

Safe multi-robotic arm interaction

Explored Control Barrier Functions for safe interaction between multiple robotic arms, addressing computational challenges in real-time deployment. Developed and conducted physical experiments with two Franka Emika Research 3 arms to validate the approach.

Read the related publication  ↗
03 Autonomy & semantic mapping

Online planning with LLMs and semantic scene graphs

Contributed to a real-time onboard framework for quadruped navigation in unknown, dynamic environments. Designed the hierarchical scene graph and implemented an LLM-based planner that generates and revises plans using real-time scene updates.

Read the autonomous navigation preprint  ↗
04 Language & task planning

Grounded LLM-based robot task planning

Explored LLMs in robotic task planning and developed methods for reliable, grounded plans aligned with the environment and the robot’s capabilities.
